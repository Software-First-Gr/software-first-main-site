Under the hood

Clean Architecture, wired for real-time.

CQRS with MediatR, EF Core on PostgreSQL, OpenSearch for instant catalog search, Valkey HybridCache, gRPC for the basket hot-path and SignalR pushing live order state to every client.

● requests  ·  ● data access  ·  ● SignalR real-time push

🧱 Domain-driven core

Rich aggregates — Order, Catalog, Shop, Invoice — keep business rules pure and infrastructure swappable.

🛡️ Idempotency pipeline

Client command IDs and optimistic concurrency (xmin tokens) make critical writes safe under retries.

📡 Full observability

OpenTelemetry traces, Prometheus metrics, Loki logs, Jaeger — every request visible end-to-end.

🧪 Testing-first culture

Unit, Testcontainers integration, Playwright E2E and NBomber load suites gate every release.
