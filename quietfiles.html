The tools

Pick a converter. Drop a file. Done.

Each tool works right on the page — drop zone above the fold, multi-file batches, and results that download straight out of your browser.

📱

HEIC to JPG

.heic → .jpg

iPhone photos come out of the camera as HEIC — efficient for storage, awkward everywhere else. QuietFiles decodes them with libheif compiled to WebAssembly and hands back universal JPGs, without your photos ever leaving the room.

  • Multi-file batches in one go
  • Personal photos stay personal — zero upload
  • Works in Chrome, Safari, Firefox and Edge

📄

PDF to JPG

.pdf → .jpg

Renders every page of a PDF into a crisp JPG image using Mozilla's pdf.js — parsed and rasterised locally, page by page. Contracts, statements and IDs are exactly the files you shouldn't be uploading to a stranger's server.

  • Every page converted in one click
  • Documents never touch a server
  • Free, no watermarks, no page limits

Under the hood

The pipeline never crosses this line.

Most "free online converters" are an upload form in disguise: your file goes to their server and you trust them to delete it. QuietFiles inverts the architecture — the converter comes to you.

● your file, in motion — always inside the dashed line  ·  ✕ the network path QuietFiles never takes

The quiet part

Privacy as architecture, not policy.

We can't lose, sell or leak files we never receive. That's a stronger guarantee than any privacy policy — and you can verify it yourself in your browser's network tab.

🔒

No uploads

Conversion happens in the page. Open the network tab and watch: after load, nothing leaves your machine.

👤

No accounts

No sign-up, no login, no email capture, no "free tier" to outgrow. Open, convert, close.

🍪

No cookies

No cookie banner because there are no cookies — and no cross-site trackers or ad networks either.

📴

Works offline

Once the page has loaded you can go airplane-mode — conversion is local, so it keeps working.

⚡

Fast by design

Static pages from Cloudflare's edge, zero JavaScript until you pick a file, WASM loaded lazily.

🆓

Free, sustainably

Your device does the compute and a CDN serves the files — near-zero running cost means it stays free.

Built with

A small site, held to a serious bar.

The same standard we hold for client work: strict TypeScript, a hard performance budget, and the lightest tool that does the job.

Astro — static output, zero JS by default TypeScript — strict mode Tailwind CSS libheif → WASM — HEIC decode pdf.js — PDF rendering Canvas API — native encode Web Workers — never blocks the UI Cloudflare Pages — edge hosting

🚀 Zero-JS by default

Astro ships plain HTML and CSS; JavaScript hydrates only the converter island, only when you use it.

🧵 The UI never freezes

Decoding runs in Web Workers off the main thread, so the page stays responsive through big batches.

📈 Speed is the strategy

Lighthouse 95+ on mobile is a hard requirement, not polish — performance is how a tool site earns its ranking.
